# Mi Aire — Documentos Legales

Repositorio público que hospeda los documentos legales de la aplicación **Mi Aire**, del
Centro para el Futuro de las Ciudades del Tecnológico de Monterrey.

## Contenido

- [Términos y Condiciones de Uso y Aviso de Privacidad](index.html)

Un solo documento reúne ambas cosas: los Términos y Condiciones y el Aviso de Privacidad.
La aplicación lo abre desde la pestaña **Conoce**, y es también la URL declarada en el
campo *Privacy Policy URL* de App Store Connect.

## Publicación

Este repositorio usa GitHub Pages. El documento queda disponible en:

https://centrofuturociudades.github.io/MiAire-privacy/

## Cómo actualizarlo

El texto legal lo redacta el área correspondiente y llega como documento de oficina
(`.odt` / `.docx` / `.pdf`). Para publicar una revisión:

1. Trasladar el texto a `index.html`, respetando la estructura de secciones existente.
2. Actualizar la línea *Última actualización* al inicio del documento.
3. Verificar que no queden comentarios de revisión del documento original en el texto
   publicado.
4. Hacer commit y push a `main`; GitHub Pages republica automáticamente.

`index.html` es autocontenido —los estilos van en el propio archivo— y se adapta a
pantallas de teléfono y al modo oscuro del sistema.
